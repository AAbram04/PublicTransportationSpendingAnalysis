Public Transportation Spending Analysis
CS 131 Big Data - Semester Team Project

DATASET
  NTD Operating Expenses by Type, 2020 (instructor-altered version).
  The dataset is NOT included in this repository/submission.
  Place it at:   data/raw/Operating_Expenses_by_Type_2020.csv
  Source URL:    TODO
  SHA-256:       TODO (printed to logs/errors.log on every run)

HOW TO RUN
  From the project directory:
      ./analyze.sh
  Exit status 0 = success, non-zero = failure (see logs/errors.log).
  Safe to run more than once; generated files are overwritten.

REQUIREMENTS
  bash, awk, sed, grep, sort, uniq, cut, sha256sum

DIRECTORY CONTENTS
  analyze.sh            Entry point; runs every stage in order
  scripts/lib.sh        Shared paths and logging/validation helpers
  scripts/01_inspect.sh Raw-data investigation -> diagnostics
  scripts/02_clean.sh   Cleaning/transformation -> data/clean/
  scripts/03_analyze.sh Analysis -> output/
  data/raw/             Original dataset (never modified, not committed)
  data/clean/           Cleaned data generated by the workflow
  output/               Analysis results
  logs/                 errors.log (run log), cleaning.log (data problems)
  docs/                 Data dictionary, cleaning plan, report drafts
  tests/                Small valid/invalid CSVs for testing the scripts
